
# 🔐 Random Password Generator

A responsive password generator built using HTML, CSS, and JavaScript.

## Features

- Adjustable password length from 4 to 32 characters.
- Uppercase and lowercase letter options.
- Number and symbol options.
- Includes at least one character from each selected type when possible.
- Generates a randomized password.
- Copy-to-clipboard button.
- Handles the case where no character type is selected.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `index.html` — Page structure
- `style.css` — Styling
- `script.js` — Password generation and clipboard logic

## How to Use

1. Choose the password length.
2. Select the character types you want.
3. Click **Generate Password**.
4. Click **Copy** to copy the generated password.
